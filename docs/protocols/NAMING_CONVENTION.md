## Scenario Families

Normal baseline:

N0 - Normal stable baseline

Normal nuisance conditions:

N1 - Position variation
N2 - Orientation variation
N3 - Movement
N4 - Weak legitimate signal
N5 - Ordinary interference
N6 - Network congestion
N7 - Legitimate multi-BSSID behaviour

Controlled abnormal scenarios will be assigned during D4 and must not be
performed before authorization and protocol approval.

Review scenarios will be assigned during D5.

## Canonical Session ID

The canonical session_id is generated by COLLECTOR_V1.

Pattern:

DEVxx_YYYYMMDDTHHMMSSZ_XXXX

Fake example:

DEV01_20261011T130000Z_A1B2

Rules:

- use the exact ID emitted by COLLECTOR_V1
- do not independently construct a second session ID
- copy the exact collector-generated ID into the external session manifest
- UTC timestamp is embedded by the collector
- no spaces
- no colon characters
- one unique ID per collection session
- never reuse a session ID
- external metadata links through this exact session_id

network_code, scenario_id, ground_truth, location_code, position_code,
orientation_code, environment_condition, operator_id and operator_notes are
stored in the external session manifest and are not encoded into session_id.
